## 🛠️ Cómo Añadir una Nueva Demo Comercial
1. Crea una nueva carpeta en la raíz (ej: `gimnasio-fit/`).
2. Coloca su `index.html` interactivo y sus recursos (logos, `og-image.png`).
3. Añade la tarjeta correspondiente en `index.html` con su botón de previsualización y texto de WhatsApp.
4. Haz `git add .`, commit y `git push origin main`.
